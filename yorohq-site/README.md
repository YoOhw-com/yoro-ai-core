# YoRo AI static site

Static files for `https://yorohq.com`.

The public pages identify YoRo AI as a brand, hosted API service, and WordPress integration project owned and operated by YoOhw Studio (`https://yoohw.com`). They also identify `yorohq.com`, `support@yorohq.com`, and the YoRo AI Core WordPress plugin as official YoRo AI resources.

Required public URLs:

- `/`
- `/terms/`
- `/privacy/`

Upload the contents of this folder to a static host such as Cloudflare Pages, Netlify, Vercel, S3 + CloudFront, or any HTTPS web server. Configure `yorohq.com` to serve `index.html` from this folder and to support directory index files for `/terms/` and `/privacy/`.
