Service role

AI workflows for store operators.

YoRo AI is designed for practical commerce work: reading store context, interpreting natural-language requests, preparing structured plans, and returning responses that the WordPress plugin can safely display or execute.

Understand requests

The official YoRo AI API receives chat instructions and relevant store context from an authorized WordPress user, then returns structured assistant responses.

Plan actions

The service prepares action plans for supported store tasks. The plugin enforces local policy, previews, permissions, and confirmation before changes run.

Draft replies

When requested, YoRo AI can draft customer email content using the order, customer, mailbox, and store context needed for that reply.

WordPress integration

Built to work with YoRo AI Core.

YoRo AI Core is the official WordPress connector for the YoRo AI service. It connects WooCommerce to a configured YoRo AI API endpoint and does not contact the service until an administrator provides a service URL and site key or starts the account connection flow.

  • WordPress sends the site URL, plugin version, language settings, selected WooCommerce context, and the user’s instruction when a request is made.
  • Order, product, customer, and mailbox data may be sent when needed to answer a request, draft an email, or prepare an action plan.
  • Approved store actions execute locally in WordPress through WooCommerce APIs, subject to user permissions and confirmation policy.
  • Execution status and action metadata may be sent back to YoRo AI API for conversation history, diagnostics, and continuity.
Administrator-controlled connection.

Each WordPress site owner is responsible for configuring the YoRo AI API URL, site key, mailbox connection, and store policies appropriate for their business.
